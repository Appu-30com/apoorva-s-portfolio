# Apoorva M P — Professional Portfolio & Engineering Showcase

A modern, high-aesthetic developer portfolio built with **React 19**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

---

## 🌟 Highlights & Features

- **Dynamic Hero & Visual Centerpiece**: Stats banner (1.5+ Years Exp, 30+ REST APIs, 7+ Role Modules, 10+ Enterprise Components), animated status radar, interactive tech pills.
- **Interactive Resume Modal**: Instant formatted view, printable PDF layout, one-click text clipboard copy.
- **Architectural Pillars & About Section**: Detailed career narrative spanning Mindstack Solutions, Conwio Radar, CCSI, and mobile Flutter development.
- **Interactive Skill Matrix**: Grouped by Frontend, Mobile, Backend, Languages, Testing & DevOps, and AI-assisted workflows (Cursor, Windsurf, Trae).
- **Career Timeline**: Interactive company milestone cards with 7 role-based module badges and impact metrics.
- **Projects Showcase**: Filterable categories (All, Enterprise & AI, Full-Stack Web, Mobile Flutter) with comprehensive "Technical Specs" modals.
- **Education & Credentials**: KSOU MCA, Bharathi College B.Sc CS, Mindstack Solutions Certificate, and Bosch BRIDGE program.
- **Interactive Contact Hub**: One-click email & phone copy, WhatsApp connect, and quick direct messaging.
- **Theme Switcher**: Smooth Dark & Light mode support.

---

## 🛠️ Tech Stack

- **Frontend**: React.js, TypeScript, Tailwind CSS, Redux Toolkit, Framer Motion
- **Icons**: React Icons, Lucide React
- **Tooling & Build**: Vite, PostCSS, ESLint, Prettier

---

## 🚀 Getting Started

### 1. Install Dependencies

```bash
npm install
```

### 2. Run Locally in Development Mode

```bash
npm run dev
```

### 3. Build for Production

```bash
npm run build
```
